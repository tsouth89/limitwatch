How to read this
Confidence — official provider page · announced blog/exec post · community 3rd-party measured · crowdsourced user reports
Sources — values with a dotted underline are quotes: hover to read the exact source sentence, click to pin it. Every row also links its src.
Units — messages, tokens, and requests are absolute caps. 5× Pro is a relative multiplier with no published absolute. $20 usage is a monthly dollar credit, not a throughput cap.
Windows — /3h /4h /5h /day /wk /mo is the refresh period. ? means the provider hasn't published a number.
